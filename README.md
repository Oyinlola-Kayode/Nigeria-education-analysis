---

## Project Overview

This project investigates Nigeria's education system using 65 years of World Bank data (1960–2025), covering 9,722 records and 449 education indicators. It follows the **DIG Framework** to systematically profile, interrogate, and derive insights from the dataset.

**Master Research Question:**  
*"How has Nigeria's declining investment in education shaped who gets left behind — and is there any hope for the future?"*

---

## Four Stories from the Data

| # | Story | Key Finding |
|---|-------|-------------|
| 1 | The Spending Collapse | Nigeria cut education spending by **90% in 50 years** — from 3.21% to 0.32% of GDP |
| 2 | 9M Children Left Behind | **9.07 million children** are still out of school; girls make up 51.6% of them |
| 3 | The Gender Literacy Reversal | Female youth literacy **overtook male** (81.43% vs 81.31%) for the first time in 2024 |
| 4 | Connecting the Dots | Despite the spending collapse, literacy improved — NGOs and private schools are filling a **$17.6B annual gap** |

## How to Run the Python Analysis

### 1. Download the Dataset
Go to: https://data.humdata.org/dataset/world-bank-education-indicators-for-nigeria  
Download the CSV file and save it to a known path.

### 2. Install Dependencies
```bash
pip install pandas matplotlib seaborn
```

### 3. Run the Script
```bash
python analyze.py --file /path/to/education_nga.csv
```

**Optional:** Specify a custom output directory:
```bash
python analyze.py --file /path/to/education_nga.csv --output my_results
```

### 4. View Outputs
All charts and the summary CSV will be saved to the `output/` folder.

## Methodology

This analysis follows the **DIG Framework**:

- **D — Describe:** Profile the dataset — dimensions, types, time range, completeness
- **I — Introspect:** Find patterns, trends, anomalies, and gender dynamics
- **G — Goal Setting:** Define a research question and structure findings into stories

**AI Collaboration:** Claude AI (Anthropic) was used as a collaborative analytical tool. All interpretations and conclusions were reviewed by the analyst.

---

## Limitations

1. **No sub-national data** — All indicators are at national level; state/zone variation is hidden
2. **Sparse literacy data** — Only 6 data points for adult literacy across 33 years
3. **Outdated completion rate** — Primary completion rate last recorded in 2010
4. **Temporal gaps** — Out-of-school data has an 11-year gap (2010–2023)
5. **Correlation ≠ causation** — No causal claims are made; findings are descriptive
6. **Informal education excluded** — Quranic schools and apprenticeships are not captured
